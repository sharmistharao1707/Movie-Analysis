# Movie Rating and Analysis CLI

A Python-based command-line application for managing a movie dataset and visualizing ratings using `pandas` and `matplotlib`.

## Features

- **Data Persistence:** Automatically initializes and updates a local `movies.csv` file.
- **CRUD Operations:** View the full dataset, inspect dimensions, add new movie records, and delete existing movies by ID.
- **Data Visualization:** Generate Line Graphs, Bar Charts, and Histograms to analyze movie ratings.
